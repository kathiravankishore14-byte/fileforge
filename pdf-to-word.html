Accepts: PDF files

PDF to Word pulls the actual text out of a PDF and rebuilds it as an editable .docx file you can open straight in Microsoft Word or Google Docs. It's meant for the common situation where you have a PDF but need to actually edit its wording — updating an old contract template, reusing a paragraph from a report, or fixing a typo in a document you no longer have the source file for.

How this tool works

Your PDF is opened in your browser with pdf.js, which reads the text layer already embedded in the file — the same underlying text a PDF viewer lets you select and copy. The tool pulls that text out page by page, then hands it to a Word-document library (docx) that builds a new .docx file: each page's extracted text becomes a heading labeled "Page 1", "Page 2", and so on, followed by that page's text as plain paragraphs. This is a text-extraction-and-rebuild process, not a visual conversion, so it reproduces the words accurately but not the original page's exact fonts, spacing, images, or table layout.

How to convert a PDF to Word

  1. Drop your PDF on the box above, or click to browse and select it.
  2. Click the button to start — there's nothing to configure.
  3. Text is read from every page and rebuilt into a Word document locally in your browser.
  4. Download the .docx file and open it in Word, Google Docs, or LibreOffice.

Privacy and local processing

Your PDF stays on your device. Reading its text layer and assembling the Word file both happen inside your browser's JavaScript engine, so the file is never uploaded and OnlineToolsWeb never sees its contents. Once the page has loaded, conversion keeps working without an internet connection.

Practical limitations

This tool extracts text — it doesn't OCR images, so a scanned page with no existing text layer converts to a mostly empty result, since there's no embedded text for it to find. Multi-column layouts (like newsletters or academic papers) can come out with lines from both columns interleaved, since text is pulled in the order the PDF stores it rather than the order a human reads it visually, so some manual reordering may be needed afterward. Original formatting — fonts, exact spacing, images, and tables — isn't reconstructed; you get the words, organized by page, ready to reformat in Word. Very long or text-dense PDFs take longer to process since every page's text is read individually before the document is assembled.

Common ways people use this tool

Typical uses include pulling text out of an old contract or template PDF so it can be edited and reused, recovering a paragraph or section from a report when the original word-processor file is gone, getting a rough editable draft from a PDF before doing a proper reformatting pass, and extracting written content for repurposing elsewhere without retyping it by hand.

Frequently Asked Questions

Will my PDF's original formatting, images and tables carry over?

No. This tool extracts the plain text from your PDF's text layer and rebuilds it as a new Word document — fonts, images, tables, columns and exact layout are not preserved. Each page's text becomes a heading followed by plain paragraphs, ready for you to reformat.

Does this work on scanned PDFs?

Only if the scan already has a text layer (for example, from a scanner or app that ran OCR when the PDF was created). This tool doesn't perform its own OCR — it reads the text layer that's already embedded in the PDF, so a purely image-based scan with no underlying text will produce a mostly empty Word document.

How is the text organized in the Word file?

Each page of your PDF becomes its own section in the Word file, starting with a "Page 1", "Page 2" heading followed by that page's extracted text as plain paragraphs — so you can see exactly which page each piece of text came from and reformat it from there.

What happens with multi-column layouts?

Text extraction follows the order the PDF stores its text in, which doesn't always match the visual reading order of a multi-column layout. Newsletter- or academic-paper-style columns may come out with lines interleaved from both columns rather than one column followed by the other — you may need to reorder some paragraphs after converting.

Is the output a real .docx file I can open in Microsoft Word?

Yes. The result is a standard .docx file built with an actual Word document library, so it opens directly in Microsoft Word, Google Docs, LibreOffice, and any other app that reads .docx files — no special import step needed.

Can I convert a password-protected PDF?

Not directly. The text layer can't be read from an encrypted PDF without its password. Remove the password first using Unlock PDF, then convert the unlocked file.
