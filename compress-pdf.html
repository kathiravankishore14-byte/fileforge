Accepts: PDF files

Compress PDF reduces the size of a PDF file by re-encoding the images inside it at a lower quality, while leaving the document's actual text and vector graphics completely untouched. It's the tool to reach for when a scanned form, report, or photo-heavy PDF is too large to email, upload to a portal with a size limit, or attach to a job application.

How this tool works

The tool opens your PDF and scans every embedded object looking for images that are already stored internally as JPEG data. Each one it finds is decoded, redrawn onto a canvas, and re-encoded as a fresh JPEG at the quality level you chose — Low, Medium, or Extraordinary — and the new, smaller version replaces the original inside the file, but only if it actually came out smaller. Alongside that, the tool strips invisible authoring metadata (like the name of the software that last saved the file) and, where it's safe to do so, removes any objects nothing in the document still references — often leftovers from a previous editor's saves. That cleanup pass is verified before it's kept: the result is reopened and checked that every page is still present, and if anything looks off, the tool automatically redoes the compression without the cleanup step rather than risk handing you a broken file. None of this touches actual text characters or vector line art, which are copied through exactly as they were.

How to compress a PDF

  1. Drop your PDF on the box above, or click to browse and select it.
  2. Choose an image quality: Low for the smallest file, Medium for a balance, or Extraordinary to keep images looking closest to the original.
  3. Click Compress. The tool scans, recompresses, and cleans the file locally in your browser.
  4. Download the result — the page shows your original size, new size, and percentage saved.

Privacy and local processing

Your PDF is never uploaded. Every step — scanning, decoding images, re-encoding them, and cleaning up the file — runs in your browser's own JavaScript engine on your device, and the file never reaches a server. Once the page has loaded, compression keeps working the same way even without an internet connection.

Practical limitations

Compress PDF only recompresses images already stored inside the PDF as JPEG data — a document made up of text and vector graphics, or one whose images use a different internal encoding, may see little or no reduction, and you'll see a message explaining the file is already about as small as it gets. Because every image is decoded and re-encoded in your browser's memory, a file with many large, high-resolution photos will take longer and use more memory than a short text-based document, and very large files can run slowly on lower-memory phones and older devices. The tool won't reduce quality below what you choose in the dropdown, so if a file still feels too large after compressing at Low, the remaining size is likely coming from content the tool intentionally leaves alone, like vector graphics or fonts.

Common ways people use this tool

People typically use this before emailing a scanned contract or application packet that's grown too large for an inbox's attachment limit, before uploading a PDF to a portal or form that enforces a maximum file size, to make a photo-heavy report or portfolio faster to share and open, and to tidy up a PDF that's picked up extra bloat from being edited and re-saved multiple times in different tools.

Frequently Asked Questions

Why didn't my PDF get any smaller?

Compress PDF only recompresses images that are already stored inside the PDF as JPEG data. If your file is mostly text and vector graphics, or its images use a different internal encoding, there's nothing for the compressor to shrink — you'll see a message saying the file is already about as small as it gets rather than a corrupted or unnecessarily reprocessed file.

Which quality setting should I choose?

Medium is selected by default and is a good balance for most documents. Choose Low if file size matters more than image sharpness — for example, emailing a large scanned packet. Choose Extraordinary when the PDF contains photos or detailed graphics you don't want visibly softened, accepting a smaller size reduction in exchange.

Will compressing make my text blurry?

No. Compression only touches embedded raster images that are already JPEG-encoded — actual text characters and vector line art are copied through untouched and stay exactly as sharp and selectable as in the original file.

Does compressing remove information from my PDF?

It removes two kinds of things: invisible authoring metadata (like the name of the software that last saved the file) and, when safe, PDF objects nothing in the document points to anymore — typically leftovers from a previous editor's saves. Visible content — your text, images, and layout — is left alone. If removing unused objects would risk breaking the file, the tool automatically redoes the compression without that step.

Is there a limit on file size or number of pages?

There's no hard-coded limit. The realistic ceiling is your browser's available memory, since the whole PDF is loaded and processed there. A typical scanned document compresses in a couple of seconds; a very large file with dozens of high-resolution images will take longer and use more memory.

Can I compress a PDF on my phone?

Yes, the tool behaves the same way in a mobile browser. Because compression re-encodes each image in memory, a large file with many photos may run noticeably slower on a phone than on a desktop with more RAM available.
