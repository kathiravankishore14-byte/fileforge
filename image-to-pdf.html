Image to PDF combines one or more photos or graphics into a single PDF file, with each image placed on its own page. It's the tool for turning a stack of scanned pages, receipts, or photos into one document you can send, print, or file — without needing a scanner app or a full PDF editor.

How this tool works

Each image you add is read in your browser and placed on its own page in a new PDF, built with the jsPDF library. Rather than fitting every image onto a fixed page size like Letter or A4, each page is sized to exactly match that image's own pixel dimensions — converted to the PDF's point-based units — so a tall photo gets a tall page and a wide photo gets a wide page, with the image filling it edge to edge. Pages are added in the order your images are listed, and every image is embedded into the PDF as JPEG regardless of its original format.

How to convert images to PDF

  1. Select one or more images — drop them on the box above or click to browse.
  2. Drag any file card to reorder it — this sets the page order in the final PDF.
  3. Click the convert button. Each image is placed on its own page, entirely in your browser.
  4. Download the combined PDF, or start over with a different set of images.

Privacy and local processing

Your images stay on your device throughout. Reading each file and assembling the PDF both happen in your browser's own JavaScript engine — there's no upload step, so OnlineToolsWeb never sees or stores the images. Once the page has loaded, this keeps working the same way offline.

Practical limitations

Because images are embedded as JPEG, transparency in a PNG isn't preserved — transparent areas get filled in rather than staying see-through in the output. Every page is sized to its own image rather than a standard page size, so if you need every page to be a uniform Letter or A4 size, this tool won't do that. A warning appears past 22 images since large batches hold more data in your browser's memory at once, which can slow things down or use noticeably more memory on phones and older devices with less RAM. Very large source photos (high-resolution camera originals, for example) will also take longer to process than typical web-sized images.

Common ways people use this tool

Typical uses include turning a set of phone-camera photos of a paper document into one PDF for submission, combining scanned receipts into a single file for an expense report, assembling photographed pages of handwritten notes into a shareable document, and creating a simple PDF portfolio or lookbook from a folder of images.

Frequently Asked Questions

Does each image get its own page, and how is the page sized?

Yes. Every image you add becomes its own page in the PDF, and each page is sized to exactly match that image's own pixel dimensions rather than a fixed page size like Letter or A4. A tall portrait photo produces a tall page; a wide landscape photo produces a wide page.

Can I reorder the images before converting?

Yes. Once your images are added, drag any file card to reorder it. The order shown on screen is the exact order the pages will appear in the finished PDF.

What happens to transparent PNGs?

Images are embedded into the PDF as JPEG, which doesn't support transparency, so any transparent areas in a PNG will be filled in rather than staying see-through in the output. If you need transparency preserved, a PDF page isn't the right format for that image.

Can I combine JPG, PNG and WebP images in one PDF?

Yes — you can mix formats freely in a single batch. Each image is read and placed on its own page regardless of its original format, so a PDF can contain a JPG page followed by a PNG page followed by a WebP page without any extra steps.

Is there a limit on how many images I can add?

There's no hard-coded limit, but a warning appears once you've added more than 22 images, since large batches use more of your browser's memory while processing. You can still proceed past that warning — it's informational, not a block.

Can I combine images into a PDF on my phone?

Yes, it works the same way on a mobile browser, including dragging to reorder the images. Combining a large number of high-resolution photos will use more memory and run more slowly on a phone than on a desktop with more RAM.
