Accepts: PDF files

PDF to JPG turns every page of a PDF into a standalone JPG image, rendered exactly as the page looks — layout, images, and text all flattened into one picture. It's for the moments a PDF viewer isn't enough: dropping a page into a slide deck, posting it somewhere that only accepts images, or previewing a page's content without opening a PDF reader.

How this tool works

Your PDF is opened in your browser using pdf.js, the same rendering engine behind Firefox's built-in PDF viewer. Each page is drawn onto an in-memory canvas at 1.5 times its native size, then that canvas is encoded as a JPG at high quality. If your PDF has just one page, you get a single JPG back. If it has more than one, every page is rendered and encoded in turn, and all the resulting JPGs — named page-1.jpg, page-2.jpg, and so on — are packed into a single ZIP file for download. This is a visual rendering, not a text extraction, so scanned pages and text-based pages are treated exactly the same way.

How to convert a PDF to JPG

  1. Drop your PDF on the box above, or click to browse and select it.
  2. Click the button to start the conversion — no settings to configure.
  3. Each page is rendered to an image locally in your browser, in order.
  4. Download your JPG (single page) or ZIP of JPGs (multiple pages).

Privacy and local processing

Your PDF never leaves your device. Rendering each page and encoding it as a JPG both happen inside your browser using pdf.js running as ordinary JavaScript — nothing is uploaded to a server, and OnlineToolsWeb never sees the file's contents. Once the page and its scripts have loaded, this keeps working the same way with your browser offline.

Practical limitations

Because a JPG is a flat picture, any text on the page is no longer selectable or searchable once converted — if you need the actual text, PDF to Word or PDF to Markdown extract it instead of flattening the page. Every page is rendered and held in your browser's memory before being packaged, so a PDF with a very large number of pages, or pages with unusually large dimensions, will take longer and use more memory, which can be noticeable on phones or lower-memory devices. Password-protected PDFs can't be rendered until they're unlocked, so run those through Unlock PDF first.

Common ways people use this tool

People typically use this to drop a PDF page straight into a presentation or document as an image, to share a page on a platform or form that only accepts image uploads, to create quick visual previews or thumbnails of a document's pages, and to turn a short scanned form or certificate into an image file for printing or archiving alongside photos.

Frequently Asked Questions

What resolution are the JPG images?

Each page is rendered at 1.5x its native PDF page size before being saved as a JPG, which produces a sharp, readable image for typical document pages — comfortably larger than the page appears on screen at 100% zoom. Very high-resolution source content beyond that isn't upscaled further.

Do I get one JPG file, or a file for every page?

A single-page PDF downloads as one JPG file directly. A multi-page PDF downloads as a ZIP archive containing one JPG per page, named page-1.jpg, page-2.jpg and so on in order.

Does the text on the page stay selectable in the JPG?

No — a JPG is a flat image, so any text on the page becomes part of the picture rather than selectable, searchable text. If you need the actual text content instead of an image, use PDF to Word or PDF to Markdown, which extract the underlying text layer.

Will a scanned PDF convert differently than a text-based one?

Not really — this tool renders each page visually, exactly as it would appear if you printed it, regardless of whether that page is built from real text or is itself a scanned image. Both convert to a JPG the same way.

Will a very large or high-resolution PDF slow this down?

Yes, somewhat. Each page is rendered and encoded one at a time in your browser, so a PDF with many pages or unusually large page dimensions will take longer and use more memory than a short, standard-size document.

Can I convert a PDF to JPG on my phone?

Yes, the tool works the same way in a mobile browser. Rendering many pages at once uses more memory, so very long PDFs may convert more slowly on a phone than on a desktop.
