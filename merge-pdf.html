Accepts: PDF files

Merge PDF combines two or more separate PDF files into a single document, in whatever order you choose. It's built for the everyday moment when a report, contract, or application arrives as five separate scans and needs to become one file before you can send or file it — no desktop PDF editor required.

How this tool works

Every file you add is read directly in your browser using a PDF-handling library (pdf-lib) that runs as ordinary JavaScript — nothing WebAssembly-based, no AI model involved. For each file, the tool opens the document, copies every page from it exactly as it appears, and appends those pages to a new, empty PDF in the order the files are listed on screen. Once every file's pages have been copied over, that new combined document is assembled and handed to you as a single downloadable PDF. Because it's a page-copy operation rather than a re-render, text stays selectable, embedded images keep their original resolution, and nothing is recompressed along the way.

How to merge PDF files

  1. Select two or more PDF files — drop them on the box above or click to browse (merging needs at least two files).
  2. Drag any file card to reorder it, or use the up/down buttons — the number on each card shows its position in the final file.
  3. Click Merge PDF. Every page is combined in the browser, in that exact order — nothing leaves your device.
  4. Download the combined PDF, or start over with a different set of files.

Privacy and local processing

Your files stay on your device the entire time. The merge runs locally in your browser's own JavaScript engine — there's no upload step, so the files never reach a server, and OnlineToolsWeb never sees or stores their contents. This also means the tool keeps working the same way with your browser offline once the page and its scripts have loaded, since there's no server round-trip for it to depend on.

Practical limitations

A few things are worth knowing before you merge. Password-protected or encrypted PDFs can't be opened without their password, so they'll fail to load here — run them through Unlock PDF first, then merge the unlocked copy. Because every page is held in your browser's memory during the merge, very large jobs — dozens of files, or PDFs made of high-resolution scanned images — can slow down or, on lower-memory phones and older devices, occasionally run out of memory. Merging doesn't compress anything, so the output file size is roughly the sum of your inputs; if you need a smaller result too, run it through Compress PDF afterward. And while page content carries over exactly, document-level extras like a PDF's bookmark outline aren't reconstructed in the merged file, and complex interactive form fields can occasionally behave differently once combined with pages from another document.

Common ways people use this tool

Typical uses include combining separately scanned pages of a single paper document into one file, assembling an application packet (cover letter, resume, references) that was created as separate PDFs, stitching together monthly statements or invoices into one file for an accountant, and merging chapters or sections of a report that different people wrote and exported on their own. In each case, the goal is the same: one file to send, print, or archive instead of several.

Frequently Asked Questions

Can I change the order of the files before merging?

Yes. Once your PDFs are added, drag any file card to reorder it, or use the up/down buttons on each card. The numbered badge on each card always shows the position it will occupy in the final merged file, and the files combine in exactly that order.

Can I merge password-protected PDFs?

Not directly. This tool needs to read each file's pages in your browser, and an encrypted PDF can't be opened without its password first. If one of your files is password-protected, remove the password with the Unlock PDF tool, then merge the unlocked file.

Is there a limit to how many PDFs I can merge, or how large they can be?

There's no hard-coded limit — you can add as many files as you like. The real ceiling is your browser's available memory, since every page is held in memory during the merge. A handful of typical documents merges in seconds; dozens of large, image-heavy scans can slow down or, in rare cases, exhaust memory on lower-end devices.

Does merging reduce image quality or file size?

No. Merging copies each page's content, images and text exactly as they are — it doesn't recompress anything. The merged file's size is roughly the sum of your source files. If you also want a smaller file, run the result through Compress PDF afterward.

Will bookmarks, forms or links survive the merge?

Page content — text, images and layout — carries over faithfully. Document-level extras like a PDF's bookmark outline aren't rebuilt in the merged file, and complex interactive form fields can occasionally be flattened or behave differently once combined with other documents.

Can I merge PDFs on my phone?

Yes — the tool works the same way on mobile browsers. Very large merges (many high-resolution scanned pages) will use more memory and run more slowly on a phone than on a desktop, simply because phones typically have less RAM to work with.
