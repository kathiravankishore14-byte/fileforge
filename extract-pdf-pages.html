Accepts: PDF files

Extract Pages pulls the specific pages you choose out of a PDF and combines them into a single new file. It's for when you only need part of a larger document — a couple of pages from a long report, one section from a manual, or a handful of scanned pages buried inside a bigger file.

How this tool works

You type the pages you want as a comma-separated list, mixing individual page numbers and ranges — for example 1,3,5-7. The tool reads your source PDF in your browser, works out which pages that list refers to, and copies just those pages, in ascending order, into a brand-new PDF using pdf-lib. Any page number that doesn't exist in your document is simply skipped, and duplicate page numbers are collapsed automatically, so you always end up with one clean output file containing exactly the pages you asked for.

How to extract PDF pages

  1. Drop your PDF on the box above, or click to browse and select it.
  2. Type the pages you want, such as 1,3,5-7.
  3. Click Extract. The chosen pages are copied into a new PDF locally in your browser.
  4. Download the resulting file, containing only the pages you selected.

Privacy and local processing

Your PDF stays on your device throughout. Reading the source file and building the new PDF both happen in your browser's own JavaScript engine — nothing is uploaded, and OnlineToolsWeb never sees or stores the file's contents. Once the page has loaded, extraction keeps working the same way offline.

Practical limitations

This tool combines every page you list into a single output file — if you want each page or group to come out as its own separate file, Split PDF is built for that instead. Encrypted or password-protected PDFs can't be opened without their password, so they need to go through Unlock PDF first. Page numbers outside your document's actual range are silently ignored rather than flagged, so double-check the page count before entering a range. Very large source PDFs, or documents made of high-resolution scanned images, take a little longer to process and use more of your browser's memory.

Common ways people use this tool

Common uses include pulling just the pages you need to review or sign out of a much longer contract, saving a single chapter or section from a long report as its own file, extracting a set of specific forms from a larger scanned batch, and creating a shorter version of a document that only contains the relevant pages for a particular reader.

Frequently Asked Questions

How do I specify which pages to extract?

Type the pages you want as a comma-separated list, mixing single page numbers and ranges freely — for example 1,3,5-7 extracts page 1, page 3, and pages 5 through 7. All of those pages come out together in a single new PDF.

Do I get one PDF, or a separate file per page?

You get one combined PDF containing every page you listed, assembled in ascending page order. If you need each page or group as its own separate file instead, use Split PDF, which is built for that.

What's the difference between this and Split PDF?

Extract Pages takes one list of pages and outputs a single PDF containing just those pages — useful when you want to pull out and keep a subset. Split PDF takes comma-separated groups and turns each group into its own separate output file — useful when you want to divide a document into multiple pieces.

What happens if I list a page number that doesn't exist?

Any page number beyond your PDF's actual page count is silently ignored rather than causing an error, so it's worth checking your document's page count before entering a range.

Does extracting affect PDF quality?

No. Extracted pages are copied exactly as they appear in the source file — text, images, and layout are unchanged, and nothing is recompressed.

Can I extract pages from a password-protected PDF?

Not directly — an encrypted PDF needs to be readable in your browser before pages can be pulled from it, which isn't possible without the password. Run it through Unlock PDF first, then extract from the unlocked copy.
