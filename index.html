Frequently Asked Questions

Is my file uploaded to a server?

No. Every tool runs locally in your browser, your files never leave your device.

Do I need to create an account?

No. There's no sign-up, no login, and nothing to remember.

Is there a file size or usage limit?

No. Use any tool as many times as you like, on files of any size your browser can handle.

What file types are supported?

PDF, images (JPG/PNG/WebP/HEIC), Word, Excel, PowerPoint, plus everyday text and utility tools.

Is my data private?

Yes. Since nothing is uploaded, no one else, including us, ever sees your files.

Can I use this on my phone?

Yes. Every tool works on any modern mobile or desktop browser.

Do I need to install anything?

No. Just open the site and start using a tool.

Are the tools really free?

Core OnlineToolsWeb tools are free to use. Optional premium features may be introduced for advanced workflows such as batch processing, larger limits, saved presets, or history.
